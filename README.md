# qa-estudos-praticos
# Portfólio de Quality Assurance (QA)

## Sobre este repositório

Este repositório reúne meus estudos e exercícios práticos em Quality Assurance (QA), acompanhando minha evolução no curso QA Starter.

Meu objetivo é desenvolver conhecimentos práticos em testes de software, aprender a identificar e documentar defeitos e construir projetos que demonstrem minha evolução profissional.

O portfólio será desenvolvido progressivamente, começando pelos fundamentos e testes manuais e avançando para testes de API e automação conforme esses conteúdos forem estudados e praticados.

## Objetivos de aprendizagem

- Compreender os fundamentos, os tipos e os níveis de teste de software.
- Elaborar cenários e casos de teste com resultados esperados bem definidos.
- Executar testes e registrar os resultados obtidos.
- Identificar e documentar defeitos com passos para reprodução e evidências.
- Praticar testes funcionais, exploratórios e de regressão conforme os estudos avançarem.
- Utilizar Git e GitHub para organizar e versionar os projetos.
- Aprender testes de API e automação de testes progressivamente.
- Desenvolver uma base prática para oportunidades de estágio e QA Júnior.

## Organização do portfólio

Os materiais serão organizados progressivamente nas seguintes áreas:

- **Testes manuais:** cenários, casos de teste e resultados de execução.
- **Relatórios de bugs:** descrição dos defeitos encontrados, passos para reprodução, resultados esperados e obtidos.
- **Evidências:** capturas de tela e outros registros úteis para demonstrar os resultados dos testes.
- **Testes de API:** exercícios e projetos que serão adicionados quando essa etapa de estudo começar.
- **Automação:** scripts e projetos que serão incorporados conforme minha evolução nos estudos.

## Ferramentas e tecnologias

As ferramentas e tecnologias serão adicionadas conforme forem estudadas e utilizadas na prática. Entre os objetivos de aprendizagem estão Git, GitHub, ferramentas de testes manuais, testes de API e automação.

## Status do projeto

**Em desenvolvimento.**

Este portfólio será atualizado durante minha formação. Os projetos, resultados e evidências publicados representarão atividades efetivamente realizadas, permitindo acompanhar minha evolução de forma transparente.

## Objetivo profissional

Desenvolver competências práticas em Quality Assurance e construir um portfólio organizado que demonstre meus conhecimentos, minha capacidade de analisar resultados e minha evolução para oportunidades profissionais na área de testes de software.
